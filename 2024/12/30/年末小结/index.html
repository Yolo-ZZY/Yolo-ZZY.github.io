2024年年末小结

额，想把博客同时部署到github和腾讯云时，才发现出bug了。。。:( :joy:
我登录腾讯云一直还是用账号密码登录，我起初没在意，原来只是ssh密钥压根就没设置，但今年没时间了，等明年吧。。。:0 :cry: :sob:

这两天回老家，暂时搞不了，可能要元旦结束才能继续吧。立个小目标，一直保持到过年，要加大对于leetcode和那个傻呗毕设的投入了，服了。。。（** 但我不会忘记初心的，狠学C++!!! ** ) :sunglasses:

剩下好像没啥了，（其实今晚上感慨挺多的，一时提笔忘字）既然没想起来，说明还不是很重要，joy。。。明天还要早起，睡觉！

人真是麻烦的东西，想要吃，又怕胖；想要玩，又想睡；想要摆，又想上进。。。突然想到懒羊羊了，hhh

二六年五月有感
二六年五月有感光阴似箭啊，距离上次写有感已经过去了一年半了。期间发生太多！ 关于考研：从南航到大连海事考研二战，冲南航计算机再次失利。没有心气三战了，也不值得了。 碎碎念：南航我计算机复试都进了，面试给我刷了555……南航校园真的好美，那天我进学校复试，街道两边开满花，漂亮学姐在拍毕业照，真成我白月光学校了，悲 :cry: :sob: 无奈之下选择调剂。本来准备调剂杭电密码学，但杭师范联系了密码学导师，只能放弃。就在杭师范调剂前夜，临时突袭了大连海事大学的交通运输，居然调剂上了！ 那还用想吗？肯定去大连211啊！虽然交通运输也是天坑专业，但好在导师也是计算机方向，前途未卜啊。 关于技术：前端已死？现在还没开学，在家天天打游戏，闲下来就琢磨起当年搞的博客。 想想当年把我搞得累死累活的网页，现在用 Claude Code 几乎不用动脑就能轻松搞定。我这个前端几乎0基础的小白，也能让AI代劳把活儿干得漂漂亮亮。 我个人浅薄地认为：前端已死。 结语就这样吧！ 希望接下来的研究生生涯，不要让自己的青春后悔！ :sunglasses:
