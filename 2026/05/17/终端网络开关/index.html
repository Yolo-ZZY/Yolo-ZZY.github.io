终端网络开关

发表于2026-05-17|更新于2026-05-17|工具与折腾效率工具

一、 终端网络开关（最常用）

我们在系统里配置的环境变量别名（Alias）是控制终端流量的最高效手段。

🚀 开启代理

在终端输入以下命令：

Bash

  • 效果：终端打印 代理已开启 🚀。此时 curl、wget、git、apt 等标准 Linux 命令会自动走 Mihomo 的 7890 端口出海。

🛑 关闭代理（切回直连）

在终端输入以下命令：

Bash

  • 效果：终端打印 代理已关闭 🛑。此时立刻清空终端代理环境变量，所有流量恢复国内常规直连。

🔍 检查当前终端状态

如果你不确定当前窗口到底开没开代理，执行这行命令：

Bash

  • 判断标准：
    • 如果输出了 http://127.0.0.1:7890 ➡️ 说明代理正开启着。
    • 如果什么都没输出（白屏空行） ➡️ 说明当前是纯直连状态。

二、 后台 Mihomo 服务开关

如果你短期内完全不需要服务器挂代理，或者想要释放系统内存（约 16M 左右），可以直接控制后台内核。

  • 彻底关闭后台代理软件：

    Bash

    (执行后，Mihomo 进程退出，系统完全释放 7890 端口)

  • 重新唤醒后台代理软件：

    Bash

  • 查看软件当前死活：

    Bash

    (看到绿色的 active (running) 说明它在后台待命，看到白色的 inactive (dead) 说明它彻底睡着了)
