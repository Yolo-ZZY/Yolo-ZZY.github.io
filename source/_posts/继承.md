# 继承
## 构造与析构
``` c++
class people
{
    public:
    string name;
    protected:
    string gender;
    private:
    int age;
}
//public：public->public,protected->protected
//proteced:public/protected->protected
//private:public/protected->privated
//访问控制符不写，默认private，父类的private子类不能直接访问
class student:public people //public是访问限定符，people叫基类（父类），student叫派生类（子类）
{
    public:
    protected:
    private:
}



```

注意不能继承

## 成员函数的重写

``` c++
class BASICCLASS
{
public:
	void show()
    {
        cout << "父类成员函数" << endl;
    }
};
class SUBCLASS:public BASICCLASS
{
public:
    void show()
    {
        cout << "子类成员函数" << endl;
    }
};
int main()
{
	SUBCLASS obj;
	BASICCLASS *p = &obj;
	BASICCLASS& r = obj;
	obj.show();	//子类成员函数
    p->show();	//父类成员函数
	r.show();	//父类成员函数
	//简而言之，对象是什么类型，就调用对应的成员函数
	//父类的指针可以指向不同的子类对象！！！
}

```
## 多态
### 虚函数
与上面对比，我们在父类子类的成员函数前都加上virtual

``` c++
class BASICCLASS
{
public:
	virtual void show()	//加上virtual
    {
        cout << "父类成员函数" << endl;
    }
};
class SUBCLASS:public BASICCLASS
{
public:
    virtual void show()	
    {
        cout << "子类成员函数" << endl;
    }
};
int main()
{
	SUBCLASS obj;
	BASICCLASS *p = &obj;
	BASICCLASS& r = obj;
	obj.show();	//子类成员函数
    p->show();	//发现调用的是子类成员函数
	r.show();	//发现调用的是子类成员函数

}

```

多态：
1. 父类有virtual
2. 子类public继承
3. 子类重写virtual成员函数
4. 调用时，用父类指针指向子类对象（但调用的是子类函数）
个人理解：父类的指针可以指向不同的子类对象，若不用虚函数，则只能使用父类的成员函数，用虚函数则会调用不同子类函数

注意构造函数不能是虚函数，即创建子类对象，父类构造一定会执行（因此父类析构也一定会执行），区别只在于子类析构会不会执行
``` c++
class BASICCLASS
{
public:
	virtual void show()	//加上virtual
    {
        cout << "父类成员函数" << endl;
    }
	BASICCLASS()	//一定会执行
    {
        cout << "父类构造函数" << endl;
    }
    ~BASICCLASS()	//也一定会执行，加virtual会导致子类析构执行，不加virtual会导致子类析构不会执行，导致子类对象没有被删除
    {
        cout << "父类析构函数" << endl;
    }
};
```
### 纯虚函数
纯虚函数在抽象类中，如下所示
``` c++
class shape
{
public：
	virtual void show()=0;	//virtual xxxx（）=0；的形式，
}

```
抽象类不能被实例化，除非它的子类重写了show
如果子类的show仍然是纯虚函数，仍然不能实例化
