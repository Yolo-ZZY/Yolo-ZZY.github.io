Mihomo 服务器节点每月更新操作指南

第一步：在 Windows 本地获取最新配置

  1. 打开电脑上的 Clash Verge 软件。
  2. 进入左侧的 “订阅” 页面。
  3. 找到你的“极速云”卡片，点击右上角的 “刷新/更新” 图标，等待更新完成。

第二步：提取并“净化”配置文件（⭐ 最关键一步）

  1. 右键点击更新好的“极速云”卡片，选择 “在资源管理器中显示”。
  2. 将弹出的文件夹里那个高亮的 .yaml 文件，复制一份到你的电脑桌面上。
  3. 在桌面上把这个文件重命名为 config.yaml。
  4. 右键该文件，选择“用记事本打开”（或使用其他文本编辑器）。
  5. 按下 Ctrl + H 调出查找替换功能：
    • 查找内容填入：anytls
    • 替换为填入：trojan
  6. 点击 “全部替换”，然后按下 Ctrl + S 保存并关闭文件。

第三步：使用 WinSCP 替换服务器文件

  1. 打开 WinSCP 并连接到你的 Linux 服务器。
  2. 在右侧（服务器端）进入目录：/etc/mihomo/。
  3. 把桌面上刚才修改好的 config.yaml，直接拖拽到右侧窗口。
  4. 遇到提示时，选择 “是/覆盖” 旧文件。

第四步：在终端重启服务使之生效

  1. 打开 FinalShell 连接到服务器终端。

  2. 复制并执行以下命令重启代理内核：

    Bash

  3. （可选检查）执行以下命令确认服务亮起绿色的 active (running)：

    Bash

🎉 至此，每月的节点更新已彻底完成！ 只要你在终端里配置了之前说的快捷开关，直接输入 proxy 就可以继续畅游外网了。
